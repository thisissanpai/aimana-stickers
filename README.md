# aimana-stickers

AI Mana 回复用的表情包库。图片放在仓库根目录，`index.json` 是索引，`skill/SKILL.md` 是配套技能。

## 安装（同事看这里）

**只需要一个文件，不需要装 git、不需要克隆仓库、不需要下载图片。**

1. 下载 [`skill/SKILL.md`](skill/SKILL.md)
2. 存到自己的技能目录：

   ```
   C:\Users\<你的用户名>\.claude\skills\sticker\SKILL.md
   ```

3. 完事。新开一个对话即可生效。

索引和图片都会从本仓库的 `raw` 地址自动加载，你本地不需要存任何图片。

> **前提**：你的机器要能访问 `raw.githubusercontent.com`。访问不了的话图片会裂图，需要换镜像。

## 它做什么

让 AI Mana 在回复时自动配一张表情包。默认频率是「活泼」——几乎每轮带一张，正式交付物和严肃结论除外。

AI 会读 `index.json`，按当前语境的情绪匹配每张图的「适用」字段，命中「禁忌」的就不用。

## 目录

| 路径 | 说明 |
|---|---|
| `*.jpg` | 静图，240px 宽 |
| `*.webp` | 动图，240px 宽，q75 |
| `index.json` | 每张图的含义 / 情绪 / 适用 / 禁忌 |
| `skill/SKILL.md` | 配套技能文件，下载后放进自己的 skills 目录 |
| `_originals/` | 原始素材备份，**不进仓库**（见 `.gitignore`） |

## 格式约定

- **宽度统一 240px。** Markdown 没有尺寸控制能力，HTML 标签会被渲染器过滤（实测 `<img>` 会被当纯文本原样打出来），所以尺寸只能写死在图片文件里。
- **静图用 `.jpg`，动图用 `.webp`。**
- **不要用 GIF。** 同样内容实测大 3–6 倍：GIF 只有 256 色调色板、没有帧间压缩，实拍素材会膨胀得离谱（167×167 的图能到 935KB）。这批素材从 GIF 转 WebP 后，总量从 3314KB 降到 719KB，降幅 78%，且全彩无肉眼可见损失。
- **文件名用英文/拼音且语义化**（如 `pig-flat.webp`）。中文名进 URL 要百分号编码，各家托管处理不一致，容易间歇性裂图——本地看着好好的，别人那边裂。

## 加新图（库主）

1. 图片丢进仓库根目录，命名语义化
2. 静图缩到 240px；动图转成 WebP
3. **打开图片实际看一眼**，在 `index.json` 的 `stickers` 数组补一条：`类型` / `含义` / `情绪` / `适用` / `禁忌`
4. 同步更新 `skill/SKILL.md`（如果是规则变动）
5. 提交推送

**别凭文件名猜含义。** 动图尤其要注意——预览通常只显示第一帧，配字往往在后面几帧，得抽帧才看得到。

> ⚠️ `skill/SKILL.md` 是分发副本，和库主本机技能目录里那份是**两份文件**，改动时记得同步。
