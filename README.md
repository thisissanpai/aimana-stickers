# aimana-stickers

AI Mana 回复用的表情包库。图片放在仓库根目录，`index.json` 是索引。

## 怎么用

这个仓库本身不干活，干活的是一个叫 `sticker` 的 Skill。它让 AI Mana 在回复时自动配表情包。

1. 把 `sticker` 这个技能装到你的机器上
2. 技能里的 `SKILL.md` 会告诉 AI 什么时候配图、怎么挑、从哪儿取图
3. 图片直接从本仓库的 `raw` 地址加载——**你不需要把图片下载到本地**

> 索引 `base` 段里同时写了 `local` 和 `remote` 两个位置。AI 会**优先用本地**（快、可离线），本地没有就自动走本仓库的远程地址。所以同一个索引，作者和同事都能直接用，不用改配置。

## 目录说明

| 路径 | 说明 |
|---|---|
| `*.jpg` | 静图，240px 宽 |
| `*.webp` | 动图，240px 宽，q75 |
| `index.json` | 每张图的含义 / 情绪 / 适用 / 禁忌 |
| `_originals/` | 原始素材备份，**不进仓库**（见 `.gitignore`） |

## 格式约定

- **宽度统一 240px。** Markdown 没有尺寸控制能力，HTML 标签会被渲染器过滤，所以尺寸只能写死在图片文件里。
- **静图用 `.jpg`，动图用 `.webp`。**
- **不要用 GIF。** 同样内容实测大 3–6 倍：GIF 只有 256 色调色板、没有帧间压缩，实拍素材会膨胀得离谱（167×167 的图能到 935KB）。这批素材从 GIF 转 WebP 后，总量从 3314KB 降到 719KB，降幅 78%，且全彩无肉眼可见损失。
- **文件名用英文/拼音且语义化**（如 `pig-flat.webp`）。中文名进 URL 要百分号编码，各家托管处理不一致，容易间歇性裂图——本地看着好好的，别人那边裂。

## 加新图

1. 图片丢进仓库根目录，命名语义化
2. 静图缩到 240px；动图转成 WebP
3. 打开图片实际看一眼，在 `index.json` 的 `stickers` 数组补一条：`类型` / `含义` / `情绪` / `适用` / `禁忌`
4. 提交推送

**别凭文件名猜含义。** 动图尤其要注意——预览通常只显示第一帧，配字往往在后面几帧，得抽帧才看得到。
